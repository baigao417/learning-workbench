# 首轮试验合同

状态：第一阶段已完成，进入真实使用迭代。

## Why

用一门真实的本地中文视频课程作为第一批材料，验证 Learning Workbench 是否能把一组本地视频课程连接成一条可恢复的学习闭环，而不是只生成一批摘要文件。

## Context package

- 输入：一个本地课程文件夹（首轮为 21 个 MP4 课次）；原始视频只保留在本地输入目录；
- 产品真相源：`README.md`、`AGENTS.md`、`docs/01-product-direction.md`；
- 设计原则：闭环产品设计；主任务优先，工具服务于真实学习。

## Deliverable

第一阶段交付一条最小垂直切片：

```text
本地课程视频
→ 课程/课次登记
→ 逐字稿与时间锚点的可挂载结构
→ 学习页面状态
→ 用户备注/批注
→ 一个当天训练任务
→ 可验证的本地结果
```

## Acceptance criteria

至少完成一次真实课次的完整任务：

1. 能从输入目录登记一节课，不复制原始视频到仓库；
2. 能为课次挂载逐字稿、时间戳或明确的待处理状态；
3. 能在学习页面同时看到课程信息、学习材料和记录入口；
4. 能保存一个时间锚点或批注，并在重新打开后恢复；
5. 能生成并完成一个与当天内容相关的训练任务；
6. 能记录一个真实摩擦，并形成下一项改进；
7. 新鲜验证通过后，形成一个小而完整的本地提交。

## Evidence and metrics

- 输入登记数量与缺失项；
- 课次打开、恢复和保存是否成功；
- 时间锚点/批注能否回到原位置；
- 学习后训练是否真实发生；
- 工具切换、查找和重新整理的次数/耗时；
- 失败、未处理和待人工确认的项目清单。

## Repository gate

- 只推送代码、项目文档、脱敏配置、schema 和可复现脚本；
- 不推送课程视频、个人上传、缓存、数据库、学习记录或秘密（全部位于本地 `.local/` 与课程目录）；
- 推送前完成 `.gitignore`、精确 staged inventory 与 secret-shape 检查；
- 每个绿色切片形成小提交，经 PR 与 CI 合入 `main`。
